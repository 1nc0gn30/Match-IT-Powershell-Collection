# Match-It PowerShell Collection

Welcome to **Match-It**, a growing collection of specialized PowerShell scripts designed for fast, flexible, and automated data matching.  
Each script focuses on a different style of Excel/CSV lookups, conditional matching, and cleanup logic — perfect for SOX work, data reconciliation, and identity processing.

---

## 📦 What This Repository Contains

This repo hosts multiple **Match-It variants**, each with its own logic, behavior, and use case.  
Examples include:

- 🔄 Conditional Excel updates  
- 🔍 Multi-column matchers  
- 🧹 Cleanup-focused matchers  
- 📑 Fallback and multi-CSV matchers  
- 🧠 Smart match engines  
- 📊 Hybrid Excel/CSV processors  

## 🎯 Mission

To provide a collection of **high-performance, zero-dependency PowerShell tools** that solve real-world reconciliation and mapping problems without needing Excel formulas, external modules, or complex pipelines.
